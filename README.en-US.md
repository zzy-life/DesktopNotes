Desktop-Notes
=============

![image](Images/main.png)

It is a user-friendly note-taking application for the Windows platform.

Features: Application is extremely minimal, 500kb in size

Support for always on top, startup on boot, theme settings, etc.

How to update to the latest version?
Install the latest version of the zip package, extract it, double-click Desktop_Notes.msi, choose the first option, and wait for the installation.

**v1.3.0 new features:** Style memory function - New notes automatically apply the last settings for font, color, and transparency
